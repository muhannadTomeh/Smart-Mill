# المعصرة الذكية — Smart Olive Mill 🫒

نظام سحابي متطور وشامل لإدارة وتشغيل معاصر الزيتون الحديثة.

---

## 🌟 الميزات الرئيسية

- **إدارة الطابور والأدوار:** تسجيل وتتبع شوالات الزيتون، دور العصر، وحالة العصر الحية.
- **إصدار الفواتير الآلية وحساب الرد:** حساب نسبة الرد نقداً أو عيناً (زيت) بدقة فورية.
- **إدارة الزبائن والمزارعين:** سجل كامل لكل مزارع، فواتيره، وديونه ومستحقاته.
- **إدارة العمال والموظفين:** تسجيل الورديات، تسوية الأجور والعمولات، وتسجيل الدخول برمز PIN.
- **المخزن والصندوق المالي:** متابعة مخزون الزيت، الصندوق النقدي، ومصاريف المعصرة.
- **لوحة تحكم وإشراف شاملة (Admin):** إدارة كافة المعاصر المسجلة، الاشتراكات، وإحصائيات المنصة.

---

## 🛠️ التقنيات المستخدمة

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, shadcn/ui
- **Backend & Database:** Supabase (PostgreSQL, Auth, RLS, Edge Functions)
- **Deployment:** Vercel

---

## 💻 التشغيل محلياً

```bash

```
