# RPC security catalog

Live audit, 2026-09-16. This is a classification of the `public` SECURITY DEFINER surface; grants are not a substitute for the role/tenant checks inside lifecycle commands.

| Classification | Functions |
|---|---|
| Canonical client commands | `create_invoice_lifecycle_command`, `create_deferred_invoice_lifecycle_command`, `cancel_invoice_lifecycle_command`, `collect_invoice_receivable_lifecycle_command`, `reverse_invoice_collection_lifecycle_command`, `record_expense_command`, `void_expense_and_reverse`, `settle_payable_lifecycle_command`, `reverse_payable_settlement_lifecycle_command`, `record_oil_trade_command`, `cancel_oil_trade_command`, `record_product_purchase_atomic`, `cancel_product_purchase_command`, `adjust_product_stock_command`, `record_partner_transaction_command`, `reverse_partner_transaction_command`, `register_worker_session`, `pay_worker_command`, `reverse_worker_payment_command`, `cancel_work_record_command`, `record_cash_opening_balance_command`, `archive_master_data_command` |
| Canonical internal helpers / role predicates | `claim_financial_command`, `complete_financial_command`, `enforce_product_stock_movement`, `prevent_closed_session_modification`, `sync_oil_inventory_from_movements`, `has_active_mill_role`, `has_role`, `is_platform_admin`, `is_mill_owner_of`, `check_user_mill_access`, `get_current_mill_id`, `get_my_mill_id`, `get_auth_user_accessible_user_ids`, `get_auth_user_mill_ids`, `get_auth_user_owned_mill_ids`, `get_user_mill_id`, `rls_auto_enable` |
| Platform-admin / credential operations | `admin_delete_mill`, `admin_set_user_pin`, `set_admin_pin`, `verify_admin_pin`, `set_report_pin`, `verify_report_pin`, `log_admin_access`. SQL provisioning routes `admin_create_cashier` and `admin_create_mill` are disabled and no longer browser-callable. |
| Intentionally anonymous | `get_public_queue`, `get_public_season_display` (public display data scoped by season), `lookup_cashier_by_username` (employee login alias resolution only). |
| Legacy or dangerous, browser execution revoked | `record_expense_atomic`, `record_expense_v2`, `record_customer_payment_atomic`, `record_customer_payment_command`, `pay_worker_and_settle`, `settle_payable_atomic`, `settle_payable_command`, `record_oil_trade_atomic`, `record_oil_transaction_command`, `can_access_mill_data`, `get_effective_mill_id`, `get_my_effective_user_id`, `is_cashier`, `handle_new_user`, `handle_new_user_setup`. |

`handle_new_user` and `handle_new_user_setup` remain trigger functions, but are not RPC callable. The public queue/display warnings emitted by Supabase Advisor are intentional; their anonymous grant is documented above and limited to display/login resolution, not financial data or credentials.
